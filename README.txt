Сайт utilizator.by

Все файлы сайта лежат в этой папке, рядом с index.html.
Чтобы опубликовать на GitHub Pages:
  1. Залить ВСЁ содержимое этой папки в корень репозитория.
  2. Settings -> Pages -> Source: Deploy from a branch, Branch: main, Folder: / (root).
  3. Подождать 1-3 минуты.

Главная страница: index.html. Остальные разделы — папки с index.html внутри.
Фото лежат в папке img/.
